## 问题

当前图像生成主流范式均依赖序列化采样：自回归模型逐 token 预测，扩散模型迭代去噪，二者均需数十至数百次模型评估才能产出一张图片，推理延迟难以压缩。统一多模态模型（如 Janus、Chameleon、Show-o、Unified-IO 2）虽整合了理解与生成，但继承了自回归或掩码迭代的慢速特性，Janus-Pro-7B 在 384px 下单图延迟高达 9.5 秒 <sup>[[1]](https://arxiv.org/abs/2611.24738)</sup>。

System One 模型（如 Jev）主张“快速、并行、类型化决策”，在选项选择、目标定位、动作打分等任务上已验证单次前向即可给出结构化输出 <sup>[[1]](https://arxiv.org/abs/2611.24738)</sup>。其核心骨干是大规模预训练的视觉语言模型（VLM），蕴含丰富视觉语义知识。若能将这种“决策范式”直接推广到图像合成——把生成视为一次联合 Choice 决策——便可彻底消除序列采样开销。

然而，直接并行预测面临两大障碍：一是**全局一致性缺失**。单一提示词对应多张合理图像，若各码位独立采样 $p(c_i|x)$，预测会落入不同模式的混合体，导致区域拼接不协调（论文 Fig. 2 直观展示了这种“碎片化”伪影）<sup>[[1]](https://arxiv.org/abs/2611.24738)</sup>；二是**多任务统一架构**。文生图、图生图、稠密预测的输入输出形式迥异，需在不引入任务专用解码器、不破坏冻结骨干的前提下，用同一套参数支撑所有任务的单次前向。

Jeveration 正是针对这两个问题给出的系统性解法。

## 核心思路

Jeveration 的核心主张可概括为三点：

1. **图像即联合决策**：将 512px 图像量化为 128 个离散码（TA-TiTok tokenizer），生成过程建模为在单次前向中并行给出 128 个位置的类别选择。
2. **共享随机态协调一致性**：引入一个全图共享的随机状态序列 $z$，令所有码位条件于 $z$ 并行预测 $p(c_i|x, z)$。$z$ 充当“全局随机种子”，使并行决策耦合，捕捉码位间的全局依赖（总相关性），从而收敛到某一个连贯的模式实例。
3. **双阶段“先学分布、再学决策”训练**：直接监督目标码会导致模型忽略 $z$（因 $z$ 与目标图像独立）。因此先冻结 VLM 训练掩码模型学习图像分布 $p(c|x)$（Phase 1），再用该掩码模型作为教师，通过条件匹配（Conditional Matching）引导决策模型学会利用 $z$ 生成连贯图像（Phase 2），最后辅以置信度引导的修正目标打磨细节。

这一范式天然延伸至稠密预测：决策 token 变为空间查询，输出头改为分类或回归，同一 Checkpoint 即可完成分割、深度、法线估计。

## 方法细节

### 3.1 形式化：图像作为类型化决策

给定条件输入 $x$（文本提示或源图像），Jeveration 输出类型化决策：
- **文生图/图生图**：联合 Choice $c = (c_1, ..., c_N)$，$N=128$，每个 $c_i \in \{1..K\}$ 为码本索引。
- **语义分割**：每个空间位置的 Choice，类别为语义标签。
- **深度/法线**：每个位置的实值 Score。

稠密预测为确定性映射，图像生成则需随机性。若直接分解为独立分布：
$$p(c|x) = \prod_{i=1}^N p(c_i|x) \tag{1}$$
其最优前向 KL 近似满足：
$$\mathbb{E}_{p(c|x)}[\log q(c|x)] = \sum_i \mathbb{E}_{p(c_i|x)}[\log q(c_i|x)] \tag{2}$$
此因式分解丢弃了码位间的**总相关性**，导致各位置边缘分布虽准但联合样本不连贯。

**共享随机态**机制引入 $z \sim p(z)$，令：
$$p(c|x, z) = \prod_{i=1}^N p(c_i|x, z) \tag{3}$$
给定 $z$ 后码位条件独立，但边际分布 $\int p(c|x, z)p(z)dz$ 能捕捉码位依赖。关键在于让模型学会“读懂” $z$ 并据此协调全局。

### 3.2 架构：冻结骨干 + 共享 LoRA + 任务头

**骨干**：Qwen3.5-4B（冻结）<sup>[[1]](https://arxiv.org/abs/2611.24738)</sup>。
**适配器**：秩 256 LoRA，全任务共享。
**决策 Token**：
- 生成任务：追加 $N=128$ 个决策 token，初始嵌入编码 $z$。$z$ 的构造：每位以概率 $\gamma=0.5$ 掩码，其余填均匀随机码，全位置加高斯噪声 $\sigma=1.0$（沿用 Di[M]O 设置）<sup>[[1]](https://arxiv.org/abs/2611.24738)</sup>。
- 稠密任务：决策 token 为空间查询，初始化为可学习向量加视觉 token 投影。
**注意力掩码**：全注意力层中，决策 token 双向互相可见，输入前缀保持因果。
**输出头**：
- **生成头**：Transformer Head 读取决策 token 末层隐状态与 $z$ 输出特征 $h_i$。双分支预测 logits：
  - Codebook 分支：投影到码空间，分类器权重初始化为 tokenizer 码本。
  - Wide 分支：零初始化，直接映射到 logits，提供额外容量。
  - 最终分布：$p(c_i|x,z) = \text{Softmax}(W_{cb}h_i + W_{wide}h_i)$。
- **稠密头**：各任务独立轻量头（分割用 CE，深度用 $L_1$，法线用余弦相似度）。

推理时，所有任务均为单次前向：生成任务并行采样 128 码送解码器（解码器微调支持 512px，图生图额外接源图门控分支）；稠密任务直接回归输出。

### 3.3 双阶段训练：从分布建模到决策蒸馏

#### Phase 1：掩码建模——学习图像分布 $p(c|x)$
保持 VLM 冻结，仅训练 LoRA 与生成头。对目标码 $c$，随机掩码集合 $M$，预测被掩码位：
$$\mathcal{L}_{mask} = -\sum_{i \in M} \log p_\theta(c_i | c_{\backslash M}, x) \tag{4}$$
可见码提供图像特定上下文，迫使模型学习码位间依赖。训练约 92k steps。得到冻结教师模型 $M_{mask}$ 与同步更新的辅助模型 $M_{aux}$（初始为 $M_{mask}$ 副本）。

#### Phase 2：决策蒸馏——学会利用 $z$ 生成连贯图像
决策模型 $M_{dec}$ 从 Phase 1 权重初始化。每步采样 $z$，单次前向得 logits $\pi$，并行采样全码序列 $\hat{c}$。随机重掩码子集 $M'$，让两个掩码模型基于相同可见码 $\hat{c}_{\backslash M'}$ 预测隐藏位：
- $M_{mask}$（冻结）给出目标条件分布 $p_{target}$。
- $M_{aux}$（跟随 $M_{dec}$ 分布训练）给出当前分布 $p_{aux}$。

最小化两者在掩码位上的 KL 散度：
$$\mathcal{L}_{match} = \sum_{i \in M'} D_{KL}(p_{target}(c_i|\hat{c}_{\backslash M'}, x) \| p_{aux}(c_i|\hat{c}_{\backslash M'}, x)) \tag{5}$$
梯度仅回传给 $M_{dec}$（$p_{target}$ 停止梯度）。直觉：只有当 $M_{dec}$ 生成的 $\hat{c}$ 内部自洽（即各码位协调对应同一张真实图像），两个教师在相同上下文下的预测才会一致；否则 $M_{mask}$ 会给出“修正后”的分布，推动 $M_{dec}$ 调整 $z$ 的使用方式。$M_{aux}$ 同步在 $M_{dec}$ 样本上做掩码建模损失，追踪学生分布变化。

**置信度引导修正**：Phase 2 后期，每批次部分样本选取置信度最低的 50% 位置重掩码，让 $M_{mask}$ 迭代补全若干轮得“修正码” $\tilde{c}$，监督 $M_{dec}$ 直接预测 $\tilde{c}$（交叉熵损失）。这在分布匹配奠定全局结构后，进一步修饰局部细节。

**稠密任务监督**：NYUv2 数据集，标准损失函数，与生成任务联合训练。

## 证据与结果

### 文生图：速度与质量的 Pareto 前沿
单 H200，Batch 1，端到端 77.8 ms 生成 512px 图像，**较 Janus-Pro-7B 加速 122 倍**（9.5s → 78ms）<sup>[[1]](https://arxiv.org/abs/2611.24738)</sup>。GenEval 0.74，超越所有列出的统一模型（Janus-Pro-1B 0.73、Show-o Turbo 0.63、MMaDA-8B 0.63），且显著快于四步 Show-o Turbo（94ms）。对比生成专用模型：在同分辨率下 GenEval 高于多步扩散模型，且速度快 5-8 倍；甚至超越 SANA-Sprint、FLUX.1-schnell、SDXL-DMD2 等生成 1024px 的单步模型（GenEval 0.72/0.69/0.56）<sup>[[1]](https://arxiv.org/abs/2611.24738)</sup>。定性样本（Fig. 1, 4）展示了复杂语义组合（茶杯里的龙、彩绘玻璃凤凰）的连贯渲染。

### 图生图：结构保真与风格控制
同一 Checkpoint 处理边缘→图像、深度→图像、灰度上色、风格迁移（动漫、吉卜力、水彩）。结构保真度指标：HED 边缘 F1 0.880、深度准确率 0.802、上色边缘 F1 0.937，显著优于“无源图解码器”基线（0.792/0.767/0.757）与“直接复制输入”基线 <sup>[[1]](https://arxiv.org/abs/2611.24738)</sup>。推理仅增 14ms（91.7ms 总计），证实可控生成无需迭代采样。

### 稠密预测：与任务专用模型持平
NYUv2 测试集：语义分割 mIoU 67.7，与同骨干单任务模型（67.8/67.3）基本持平，远超 DeepLabV3+ R50（53.5）<sup>[[1]](https://arxiv.org/abs/2611.24738)</sup>。深度绝对误差 0.267m（专用模型 0.246/0.253，DeepLab 0.393）。法线平均角度误差 24.2° 略逊于专用模型（21.2°/23.0°），论文归因于精细局部几何对共享容量最敏感。推理延迟约 78ms。

- **双分支头互补**：Codebook 分支继承 tokenizer 结构先验，Wide 分支提供额外表达力，合并显著优于单分支。

- **联合训练无干扰**：全任务训练与仅文生图训练在 GenEval (0.74 vs 0.73)、HPS (28.06 vs 28.28)、DPG (78.24 vs 78.61) 上无统计学差异 <sup>[[1]](https://arxiv.org/abs/2611.24738)</sup>。

## 我们的看法

### 方法成立的前提
1. **强预训练 VLM 是基石**：Qwen3.5-4B 提供了足够丰富的视觉语义表征空间，使得仅通过 LoRA 适配即可支撑生成与感知双重任务。若骨干容量不足或预训练数据分布偏差大，共享适配器极易产生任务干扰。
2. **高质量离散 Tokenizer**：TA-TiTok 将 512px 压缩为 128 码（压缩率约 256×），码本语义足够紧凑，使得“单次并行选择码本条目”成为合理的决策空间。若码长过长或码本语义松散，并行决策的组合爆炸将难以收敛。
3. **掩码建模作为强教师**：Phase 1 掩码模型必须能准确建模 $p(c|x)$，才能在 Phase 2 提供可靠的条件匹配目标。这要求掩码比例、训练步数、优化器设置均需精心调节（论文未详述超参细节）。

### 可能失效的场景
- **超高分辨率生成**：128 码的信息瓶颈限制了 512px 以上的细节容量。论文解码器虽微调支持 512px，但未展示 1024px+ 结果。扩展至高分辨率需重新设计 Tokenizer 或引入层级生成，单次前向的显存与计算优势可能被稀释。
- **极端长尾/组合泛化**：GenEval 0.74 尚低于 Janus-Pro-7B 的 0.80，提示在复杂指令遵循、空间关系推理上，单次并行决策仍弱于自回归的链式推理能力。共享随机态 $z$ 的维度与表达力能否覆盖极高熵的图像分布，理论上未给出界。
- **法线等精细几何任务**：联合训练下法线误差明显劣于专用模型，说明“生成与感知共享适配器”在高频几何细节上存在容量争用。若下游极其敏感于几何精度（如自动驾驶感知），可能需任务专用适配器。

### 与已有工作的关系
- **Di[M]O / Soft-Di[M]O**：Jeveration 直接借用了“条件匹配 + 辅助模型追踪”的蒸馏框架，但核心创新在于**将学生模型从“掩码迭代生成器”改为“冻结 VLM + 共享随机态的单次决策器”**，并统一了稠密预测。Di[M]O 仍需辅助模型迭代采样，Jeveration 彻底消除了推理时的迭代。
- **MaskGIT / Muse / Meissonic**：它们是 Phase 1 的直接前身。Jeveration 证明：掩码模型学到的条件分布可作为教师信号，蒸馏出无需迭代的并行决策模型。
- **Consistency Models / MeanFlow / DMD**：连续空间单步生成的并行工作。Jeveration 在离散 Token 空间实现同等目标，且复用了 VLM 的语义理解能力，实现了真正的“理解与生成统一”。
- **Janus / Show-o / Unified-IO 2**：统一架构的前辈，但均保留序列化解码。Jeveration 展示了统一架构的**终极推理形态**——单次前向。

### 值得追问的问题
1. **共享随机态 $z$ 的理论最优维度与分布是什么？** 论文采用与码长等长的序列，每位掩码/随机码/噪声混合构造，这更像是一个工程启发式设计。$z$ 的信息瓶颈与图像分布熵的关系、是否存在更紧凑的潜变量参数化，缺乏理论分析。
2. **Phase 2 的条件匹配损失是否等价于最小化 $D_{KL}(p_{dec} \| p_{data})$？** Di[M]O 论文给出了近似论证，但在冻结骨干、LoRA 低秩适配、双分支头的约束下，收敛保证尚不明确。训练稳定性对 $M_{aux}$ 更新频率、掩码比例敏感度如何？（论文未详述）。
3. **能否消除 Phase 1，直接端到端训练？** 论文指出直接监督目标码会导致模型忽略 $z$。但为何不引入正则项（如互信息最大化 $I(c;z|x)$）强制使用 $z$，从而合并两阶段？这关乎训练工程的简化。
4. **扩展至视频/3D**：System One 范式强调“快速并行决策”，视频生成天然具有时序一致性约束，若引入时维共享随机态，能否在单次前向生成连贯视频片段？这将是该范式极具想象力的延伸方向。

Jeveration 的价值不止于刷新延迟指标，而是**验证了“冻结大模型 + 低秩适配 + 显式随机协调 + 蒸馏式训练”这一技术路线，能在单次前向内同时解决生成与感知的核心难题**。它将“System One”从决策任务推向了生成任务，为实时交互式多模态智能体（如具身智能、游戏 NPC、流式视频编辑）提供了极具吸引力的底座架构。后续工作若能在理论收敛性、高分辨率扩展、端到端训练简化上取得突破，该范式有望重塑统一多模态模型的推理标准。
